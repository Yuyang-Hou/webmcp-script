# Codex 原生自动加载验收 · 2026-09-11

环境：Codex 26.903.61454 / 8378 的签名隔离副本，独立测试 profile，启动参数 load-extension 与 WebMCPTesting。未修改正常 Codex 应用包。

本轮测试通过声明式 content_scripts 注入独立脚本，再由 Codex 自带 WebMCP 能力发现和调用。普通 `/`、`/second`、`/only` 页面响应没有 WebMCP 脚本；未使用临时 JS 注入或扩展管理页。

| 场景 | 实际结果 |
|---|---|
| 普通首页 | 自动出现 2 个工具；7 + 5 = 12 |
| 刷新首页 | 保持 2 个工具；2 + 3 = 5 |
| 完整导航 | `/second` 自动恢复工具；10 + 20 = 30 |
| 重启隔离副本并加载当前包 | `/only` 自动出现 4 个工具；11 + 31 = 42 |
| SPA 离开匹配路径 | `/other` 只保留 2 个全站工具 |
| 历史返回匹配路径 | 恢复 4 个工具；20 + 22 = 42 |
| 刷新匹配路径 | 仍为 4 个工具；30 + 12 = 42 |

首组三项使用不可变预览包；后四项使用当前源码生成的本地演示和路由演示组合包。测试报告记录了各自文件哈希，不混用版本结论。

限制：脚本更新需要重新生成包并重载；声明式首次注入按文档加载时 URL 匹配，未覆盖首次通过 SPA 从不匹配路由进入；恢复测试工具连接需要在重启后的副本打开当前任务。旧管理器选项页崩溃未确认修复，新加载路径不依赖该入口。
