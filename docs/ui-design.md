# Chrome 扩展界面

采用脚本管理器的常见结构：紧凑菜单弹窗、页签管理面板、脚本表格。使用浅灰与白色、细边框和系统字体；颜色仅用于连接和错误状态。

- 弹窗采用方案 A：网页工具默认展开，本页脚本默认收起，两组使用相同标题、数量和折叠样式。新建脚本仅出现在展开后的本页脚本内，即使没有匹配脚本也保留；管理面板在外层。正常连接位于底部，异常才上移提示。
- 脚本行：与工具条目同字号、白底，无常驻开关。名称与箭头展开“已启用 / 已停用”勾选项、编辑、删除；启停后保持展开。编辑直达该脚本，删除需确认，失败保留并提示；长名称可悬停看全名。
- 弹窗视觉：344px 宽，系统字体 13px、条目 12px、辅助说明 11px；统一 SVG 线性图标，灰色悬停、轻分割线与圆角菜单行。浅蓝仅用于未连接/连接中的提示，正常连接收在底部。
- 工具来源：弹窗按提供方分组，同一脚本名称只显示一次；缺少来源字段时只显示工具名称，不显示来源占位或刷新提示。不根据脚本名猜测归属。停用撤销已归属的原生工具和旧调用入口；普通脚本重新启用需刷新，清理失败保留明确提示。
- 管理面板：已安装脚本、网页工具、连接、设置；新建编辑器属于“新建脚本”页签本身，选中与保存均不额外创建文件页签；切换页签保留草稿。
- 管理页顶部采用单行方案 B：48px 白底横栏容纳 24px Logo、下划线页签和右侧状态。已连接仅显示小圆点，悬停及无障碍标签说明本地服务状态；未连接或连接中显示简短文字，点击进入连接设置。页签保留方案 A 的 2px 中性下划线，导航文字 15px，顺序为“网页工具、已安装脚本、新建脚本、连接、设置”，新建页签显示完整文字；长文件页签在导航内部滚动。
- 新建：预填标准元数据、唯一 namespace、网站范围和只读原生 WebMCP 示例；不依赖 `WebMCPScript` 或专有 `@id`，自行处理页面离开及缓存返回时的注册清理。可直接编辑或全选粘贴替换 → 保存 → 检查网站范围 → 确认。没有导入文件的重复入口。
- 启停：管理列表保留开关，弹窗放入脚本操作菜单的勾选项；保存期间禁用，失败恢复并提示。
- 图标角标：显示当前页面原生工具数量；断连、未配对或页面错误优先显示 `!`，悬停查看原因。检测中和不支持的页面留空，读取失败显示 `?`，不把未知状态当成零。
- 连接：默认只有“复制连接说明给 AI”和“粘贴 AI 返回的连接码”两步。AI 通过 `connection_info` 先启动服务再给出连接码，消除先配对才能启动的顺序障碍。端口和 MCP JSON 收进手动设置；成功状态仅表示浏览器与本地服务连通，提示回到 AI 调用 `pages` 完成验证。剪贴板失败提供可选中文本，错误连接码保留以便修正。
- 编辑：CodeMirror 6 提供高亮、撤销、查找、键盘支持。小尺寸中性保存按钮，未修改时禁用；源码页签显示文件名、修改标记与关闭入口。
- 恢复：文件菜单读取上一版，仍经过同一预览和并发校验。关闭未保存编辑器需要确认。
- 状态：区分原生接口不支持、读取失败、确实没有工具。连接提示只描述扩展到本地服务的连接。

参考功能结构：[Violentmonkey](https://github.com/violentmonkey/violentmonkey)、[ScriptCat](https://github.com/scriptscat/scriptcat)。编辑器采用 [CodeMirror](https://github.com/codemirror/dev)，未复制这些项目的界面代码。

## 验收边界

`pnpm test:ui` 在独立普通 HTTP 页面验证真实渲染的界面及 CodeMirror，通过模拟 Chrome 消息检查交互，输出截图和检查结果。它不安装扩展、不进入浏览器权限页面，也不证明真实页面脚本已经加载。

真实安装验收需重载构建后的 Chrome 扩展，再通过产品 MCP 与原生页面工具确认链路。Codex 的声明式扩展包与 Chrome 管理器是不同入口，不以 Chrome 界面检查替代 Codex 验收。

## 字体规范

正文、页签与代码使用 13px，表头、辅助文案及状态栏使用 12px；字重仅使用 400/500/600。正文采用系统界面字体，中文保留苹方、冬青黑体与微软雅黑回退，代码单独使用等宽字体。`body` 显式继承根字体，避免 Chrome 注入的扩展默认字体改变排版。

相关 Chromium 源码：[extension_fonts.css](https://raw.githubusercontent.com/chromium/chromium/main/extensions/renderer/resources/extension_fonts.css)。HTTP 测试通过模拟 body 字体覆盖检查这一边界，不冒充真实已安装扩展的截图。

普通操作结果使用底部浮动轻提示，3 秒后自动消失，不占用列表或编辑器高度；错误保留在原位置供用户处理。

编辑器复用 CodeMirror 默认的半透明当前行背景，避免覆盖选区；“新建脚本”只在选中时显示下划线。

连接检查默认折叠，用户点击后分别展示脚本权限、桥接状态和网页接口；结果使用普通列表，不出现常驻横幅。预构建包没有本机绝对路径时，仍可复制 AI 连接说明；手动配置提示运行包内 setup.mjs。
